# Career-Lens

Career-Lens is a resume analysis and career alignment platform. It extracts skills and experience from uploaded resumes in PDF or Word format, evaluates alignment across 29 job categories using machine learning, and identifies skill gaps.

## Setup

1. Clone the repository and enter the directory
2. Create a virtual environment: python -m venv venv
3. Activate the environment: venv\Scripts\activate
4. Install dependencies: pip install -r requirements.txt
5. Run the application: python app.py
6. Open http://127.0.0.1:5000 in your browser
